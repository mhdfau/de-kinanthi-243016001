# ADR-001: Pemilihan PostgreSQL sebagai Database Utama

**Status:** Disetujui

**Konteks:**
Batik Kinanthi membutuhkan database untuk menyimpan data transaksi dari 3 kanal penjualan (toko, web, marketplace). Data mencakup pelanggan, produk, transaksi, dan detail transaksi. Dibutuhkan database yang andal, gratis, dan mendukung query analitik.

**Opsi:**
- A. PostgreSQL — open source, fitur lengkap, mendukung JSON, gratis
- B. MySQL — open source, populer, tapi fitur analitik lebih terbatas
- C. SQL Server — fitur enterprise, tapi berbayar untuk skala besar

**Keputusan:** Opsi A (PostgreSQL) dipilih karena gratis, fitur analitik kuat, mendukung tipe data lengkap, dan komunitas besar.

**Tipe:** Two-way door (bisa migrasi ke database lain karena menggunakan SQL standar dan SQLAlchemy sebagai abstraksi)

**Konsekuensi:**
- Tim harus belajar PostgreSQL jika belum familiar
- Perlu Docker untuk kemudahan deployment
- Exit plan: karena menggunakan SQLAlchemy, migrasi ke MySQL/MariaDB relatif mudah dengan ubah connection string
